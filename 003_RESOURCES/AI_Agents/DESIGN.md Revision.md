# Design System

## Core Philosophy
- **Aesthetic:** Minimal but lethal.
- **Rules:** High contrast, zero clutter, ruthless conciseness. Absolutely no serifs. Do not use decorative flourishes.

## Typography
- **Headings (H1-H6):** `Montserrat`. Use bold font weights to establish strict visual hierarchy.
- **Body Copy:** `Noto Sans`. Keep line height optimized for readability.
- **Code Blocks:** System default monospace. 

## Color Palette
- **Primary Action (Royal Blue):** `#0e34a0`

- **Surface:** `#FFFFFF`
- **Text (Primary):** `#111111`
- **Text (Secondary/Muted):** `#666666`

## Component Guidelines
### Buttons
- Flat colors only.
- Background: `#0e34a0`.
- Text: `#FFFFFF`.
- Border-radius: 2px (sharp, structural corners, not overly rounded).

### Layout & Spacing
- Use a strict 8px grid system.
- Embrace white space to create structural separation instead of using dividing lines.

## Updated Version

```markdown
# Design System

## Core Philosophy
- **Aesthetic:** Systemic Minimalism
- **Rules:** Systemic minimalism is thoughtfully distributed complexity. It is not an attempt to _prevent_ complexity, because that would be a fool's errand. It is the recognition that complexity will emerge, but it can be intentionally managed and its impacts mitigated. High contrast, zero clutter, ruthless conciseness. Limit serifs and decorative flourishes so they actually stand out.

## Typography
- **Headings (H1-H6):** `Montserrat`. Use bold font weights to establish strict visual hierarchy.
- **Body Copy:** `Noto Sans`. Keep line height optimized for readability.
- **Code Blocks:** System default monospace. 

## Color Palette
- **Primary Action (Royal Blue):** `#0e34a0`
- **Dark Backgrounds / Anchors (Navy):** `#000B58`
- **Surface:** `#FFFFFF`
- **Text (Primary):** `#111111`
- **Text (Secondary/Muted):** `#666666`

## Component Guidelines
### Buttons
- Flat colors only.
- Background: `#0e34a0`.
- Text: `#FFFFFF`.
- Border-radius: 2px (sharp, structural corners, not overly rounded).

### Layout & Spacing
- Use a strict 8px grid system.
- Embrace white space to create structural separation instead of using dividing lines.
```
