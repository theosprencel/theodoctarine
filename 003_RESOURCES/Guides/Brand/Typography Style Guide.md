# Typography Style Guide

This is a simple guide to proper use of #fonts and #styling in accordance with the [[003_RESOURCES/Guides/Brand/Kinetic Mesh Brand System]].

---

## Headings and Paragraph Styles

This table covers the most commonly used styles, which use [Montserrat](https://fonts.google.com/specimen/Montserrat) for headings and [Noto Sans](https://fonts.google.com/noto/specimen/Noto+Sans) for paragraph elements.

<!--octarine-table-cols:109,135,160,182-->
| **Element** | **Font** | **Style** | **Size** |
| --- | --- | --- | --- |
| H1 | Montserrat | Black | 36px |
| H2 | Montserrat | ExtraBold | 32px |
| H3 | Montserrat | ExtraBold | 24px |
| H4 | Montserrat | Bold | 20px |
| H5 | Montserrat | Bold | 18px |
| H6 | Montserrat | SemiBold | 16px - ALL CAPS |
| Body | Noto Sans | Regular | 16px |
| Eyebrow | Noto Sans | Bold | 14px - ALL CAPS |
| Caption | Noto Sans | Light Italic | 14px |
| Blockquote | Noto Sans | SemiBold Italic | 16px |
| Code | DM Mono | Regular | 14px |

## Specialty Styles

We have a "secret second brand" for special use cases. It features fonts that are lighter and carry an air of elegance. Caution should be exercised and these styles should be used sparingly, not only to preserve the "exclusivity" factor, but also because the fonts can be difficult to read and can look odd if misused.

Fonts here include [Cormorant Garamond](https://fonts.google.com/specimen/Cormorant+Garamond), [Satoshi](https://font.download/font/satoshi), and [DM Mono](https://fonts.google.com/specimen/DM+Mono).

| **Element** | **Font** | **Style** | **Size** |
| --- | --- | --- | --- |
| H1 | Cormorant Garamond | ExtraBold | 36px |
| H2 | Cormorant Garamond | ExtraBold | 24px |
| H3 | Cormorant Garamond | Bold | 20px |
| H4 | Cormorant Garamond | Bold | 18px |
| H5 | Cormorant Garamond | Bold | 16px |
| H6 | Cormorant Garamond | Bold | 14px |
| Body | Satoshi | Regular | 16px |
| Code | DM Mono | Regular | 14px |
